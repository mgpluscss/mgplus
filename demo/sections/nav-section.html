Navs

Navs are used to navigate through the application. Below, you will find examples of how to use the nav system to create a variety of navigation layouts using Pure CSS and standard semantic HTML aria-current="page".

Semantic Nav (aria-current="page")

Standard semantic HTML. Mark the active page or section with aria-current="page" on the link. Mg+ styles the active state automatically with zero JavaScript required.
