Navs

Navs are used to navigate through the application. Below, you will find examples of how to use the nav system to create a variety of nav states.

Mg+ supports both modern Zero-JS native navigation using standard HTML aria-current="page", and the JavaScript plugin (data-toggle="nav") for client-side state switching.

Native Zero-JS Nav (aria-current="page")

Standard semantic HTML. Mark the active page or section with aria-current="page" on the link. Mg+ styles the active state automatically with zero JavaScript required.

JavaScript Plugin Nav (data-toggle="nav")

The JS plugin listens for clicks and dynamically swaps the .active class across items for client-side single-page interactions.
