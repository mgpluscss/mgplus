Customization

MgPlus provides a set of CSS variables that allow you to customize the look and feel of your application. Below is a list of all available variables and their default values.

Colors (OKLCH Color Space)

Mg+ uses modern oklch() for perceptually uniform colors and native light-dark() adaptive tokens.

--mg-color-dark: oklch(0.2 0.01 270) --mg-color-light: oklch(0.98 0.005 270) --mg-color-primary: oklch(0.55 0.18 260) --mg-color-red: oklch(0.55 0.22 25) --mg-color-orange: oklch(0.68 0.18 50) --mg-color-blue: oklch(0.58 0.18 240) --mg-color-green: oklch(0.65 0.18 145) --mg-color-initial: light-dark(var(--mg-color-light), var(--mg-dark-color-initial)) --mg-color-secondary: light-dark(oklch(0.3 0.02 270), var(--mg-dark-color-secondary)) --mg-color-tertiary: light-dark(oklch(0.45 0.02 270), var(--mg-dark-color-tertiary)) --mg-color-quaternary: light-dark(oklch(0.7 0.02 270), var(--mg-dark-color-quaternary)) --mg-color-quinary: light-dark(oklch(0.92 0.01 270), var(--mg-dark-color-quinary))

Dark Mode Tokens

--mg-dark-color-initial: oklch(0.2 0.01 270) --mg-dark-color-secondary: oklch(0.9 0.01 270) --mg-dark-color-tertiary: oklch(0.75 0.01 270) --mg-dark-color-quaternary: oklch(0.45 0.01 270) --mg-dark-color-quinary: oklch(0.3 0.01 270)

Open Design Tokens

Tokens are exported directly as W3C DTCG-compliant JSON format from mgplus/tokens:

import tokens from 'mgplus/tokens';

Cascade Layers

All Mg+ styles are organized into standard CSS Cascade Layers so your application styles can easily override without specificity wars:

@layer mg.reset, mg.base, mg.theme, mg.components, mg.utilities;

Typography

--mg-base-font-size: 1.6rem

Borders and Shadows

--mg-control-radius: 1rem --mg-input-radius: 1rem --mg-control-shadow: 0 0 2px rgb(0 0 0 / 20%), 0 3px 4px rgb(0 0 0 / 15%) --mg-control-active-shadow: inset 0 0 100px 100px rgb(0 0 0 / 10%)

Grid

--mg-grid-gutter: 0.5rem

Z-Index

--mg-zindex-0: 1 --mg-zindex-1: 100 --mg-zindex-2: 200 --mg-zindex-3: 300 --mg-zindex-4: 400 --mg-zindex-5: 500 --mg-zindex-max: 999
