Accordions

Mg+ provides boxed accordion components built on native Pure CSS and HTML5 primitives (<details class="mg-accordion">) with 100% zero JavaScript required. Each panel features a clean disclosure chevron indicator, smooth transitions, and out-of-the-box keyboard accessibility.

Mutually Exclusive Accordions (Native name="..." Grouping)

By utilizing the standard HTML5 name attribute, opening one panel automatically closes any other open panel within the same group natively with no JavaScript.

What is Mg+?

Mg+ is a lightweight micro CSS library built on Milligram, emphasizing modern browser primitives, pure CSS helpers, and full dark mode support.

Does this require any JavaScript?

Zero JavaScript is required. The accordions rely entirely on HTML5 <details> and CSS styling, with full keyboard navigation (Enter / Space) handled natively by the browser.

How does grouping work?

By giving sibling <details> elements the same name="demo-accordion-group" attribute, the browser natively coordinates mutually exclusive expansion.

Independent Accordions (Multiple Expandable)

Omit the name attribute to allow multiple accordion panels to remain expanded simultaneously.
