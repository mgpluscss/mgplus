Collapse

Mg+ provides collapsible and accordion components using modern Pure CSS and HTML5 (<details class="mg-collapse"> and <details class="mg-accordion">) with 100% zero JavaScript required.

Native Collapse (HTML5 <details class="mg-collapse">)

Wrap your trigger in <summary> and content in <details class="mg-collapse">. Works natively without any JavaScript, supports keyboard navigation out of the box, and rotates .mg-icon-collapse automatically.

Pure CSS Button Collapse

This collapsible section is driven entirely by native HTML5 <details> with zero JavaScript. The button chevron rotates smoothly on open/close.

Pure CSS Text Collapse

A clean text toggle trigger that expands and collapses content natively without JavaScript.

Native Accordions (HTML5 <details class="mg-accordion">)

Boxed accordion panels styled via <details class="mg-accordion"> and <summary>. Use the HTML5 name="..." attribute for native mutually exclusive accordion groups with zero JavaScript.

Panel 1: Native Disclosure

This accordion opens and closes natively without requiring any JavaScript. Keyboard navigation (Enter / Space) works out of the box.

Panel 2: Mutually Exclusive Accordion

By using the standard HTML name="accordion-group" attribute, opening this panel automatically closes sibling panels natively.
