Getting Started

Mg+ is a lightweight, modern Pure CSS library. Include the CSS file in your project and start using semantic HTML5 and predefined utility classes with zero JavaScript required.

Quick start (Pure CSS)

To quickly get started with Mg+, follow these steps:

  1. Include the Mg+ CSS file in the <head> section of your HTML file: 
    <link rel="stylesheet" href="https://cdn.mgpluscss.com/$PACKAGE_VERSION/mgplus.css" />
  2. Start using the predefined classes with standard HTML5 elements: 
    <button class="mg-button">Click me</button>

Customizable CSS Variables

To customize Mg+ variables, simply override the root variables in your CSS:

:root {
    --mg-primary-color: #3498db;
    --mg-secondary-color: #2ecc71;
    --mg-control-radius: 1.5rem;
    --mg-input-radius: 1.5rem;
    --mg-control-shadow: 0 0.4rem 1rem rgba(0, 0, 0, 0.2);
}

Pure CSS Browser Primitives (Zero-JS)

Mg+ leverages modern web platform standards out of the box with zero JavaScript:

  • Accordions & Collapses: Native HTML5 <details class="mg-collapse"> and <details class="mg-accordion">
  • Modals & Drawers: Native HTML5 <dialog class="mg-modal"> with blurred ::backdrop and <form method="dialog">
  • Popovers & Dropdowns: HTML5 Popover API <div popover class="mg-popover"> with popovertarget
  • Tabs: CSS :has()-driven tabs with hidden radio inputs
  • Responsive Grids: Modern intrinsic CSS Grid (.mg-grid) & Container Queries
  • Dark Mode: CSS light-dark() color functions matching system or data-theme attribute

Auto-Compat for Older Browsers (Optional)

For legacy browsers that do not yet support modern standards (like native Popover API, <dialog>, CSS :has(), or light-dark()), include the optional auto-compat script at the end of your page. It performs feature detection and only activates polyfills when features are missing: 

<script type="module" src="https://cdn.mgpluscss.com/$PACKAGE_VERSION/mgplus-vanilla.js?autocompat"></script>

Configure Dark Mode

Set the theme preference on your root <html> element: data-theme="dark|light|auto".

"auto" mode uses the user's system browser preference via prefers-color-scheme.
