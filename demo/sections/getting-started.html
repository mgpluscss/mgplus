Customizable css variables

To customize Mg+ variables, just override the root variables. For example: 

:root {
    --mg-primary-color: #3498db;
    --mg-secondary-color: #2ecc71;
    --mg-control-radius: 1.5rem;
    --mg-input-radius: 1.5rem;
    --mg-control-shadow: 0 0.4rem 1rem rgba(0, 0, 0, 0.2);
}

Zero-JS Modern CSS Architecture

Mg+ is designed as a modern Zero-JS micro-CSS library. Interactive components use modern HTML5 and CSS primitives without requiring any JavaScript runtime:

  • Dropdowns & Popovers: Native HTML5 Popover API ([popover] and popovertarget).
  • Modals & Dialogs: Native HTML5 <dialog class="mg-modal"> with blurred ::backdrop.
  • Accordions & Collapses: Native HTML5 <details class="mg-accordion"> and <summary>.
  • Responsive Grids: Modern Intrinsic CSS Grid (.mg-grid) & Container Queries (.mg-container-query).
  • Dark Mode: Automatic system OS theme adaptation via CSS light-dark() and color-scheme: light dark.

Configure Dark Mode

In your main HTML document, set data theme value among: data-theme=["dark"|"light"|"auto"]

"auto" mode uses system browser preference automatically with zero JavaScript.

Zero-JS Modern CSS Alternatives

Mg+ now supports zero-JS browser primitives out of the box:

  • Accordions: Native <details class="mg-accordion"> and <summary>
  • Modals: Native HTML5 <dialog class="mg-modal"> with blurred ::backdrop
  • Popovers: Native Popover API <div popover class="mg-popover"> with popovertarget
  • Responsive Grids: Modern Intrinsic CSS Grid (.mg-grid) & Container Queries (.mg-container-query)
Js extensions are optional and provided for legacy DOM interactions with navs, tabs, dropdowns, modals, etc. They can easily be replaced by native HTML5 primitives or any UI framework (React, Vue, Angular, Svelte).
