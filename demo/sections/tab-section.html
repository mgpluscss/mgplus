Tabs

Tabs are used to switch between different views within the same context. Mg+ supports both modern Zero-JS native CSS tabs (via hidden radio controls and :has()) and the classic JavaScript plugin (data-toggle="tabs").

Native Zero-JS Tabs (CSS :has() + Radio Inputs)

Create interactive tabs with zero JavaScript using hidden .mg-tabs--radio controls and standard <label> elements. The active tab and content switch natively, with built-in arrow-key keyboard navigation.

1. This is tab content displayed purely with CSS :has() and HTML radio inputs. No JavaScript loaded or executed.

2. Second panel content, activated automatically when the second radio button is selected.

3. Third panel content, with native accessibility and keyboard support (← / → arrow keys).

JavaScript Plugin Tabs (data-toggle="tabs")

If you use the Mg+ JS plugin, add data-target="id_of_tab_content" to each tab item and data-toggle="tabs" to the .mg-tabs container. The plugin automatically handles ARIA roles (role="tab", aria-selected) and active class switching.
